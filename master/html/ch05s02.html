Getting the Data

Using the API requires a token. Registration on MobilityTwin.Brussels is free, and the token is shown on the account page. The data is not bundled with the workshop: each reader downloads it with their own token. We use the positions of Monday 16 November 2026. The API returns the addresses of the Parquet files covering a time range, which are downloaded without a token. A file covers a day in UTC, that is, from 1:00 to 1:00 in Brussels. 

export MOBILITYTWIN_TOKEN=<your token>
API=https://api.mobilitytwin.brussels
# The Parquet file of the vehicle positions of Monday 16 November 2026 (UTC)
curl -s -H "Authorization: Bearer $MOBILITYTWIN_TOKEN" \
  "$API/stib/vehicle-trip/parquet?start_timestamp=2026-11-16T00:00:00Z&end_timestamp=2026-11-17T00:00:00Z"
# {"results": ["https://.../2026-11-16_00-00-00_to_2026-11-17_00-00-00.parquet"]}
curl -s -o stib_2026-11-16.parquet \
  https://motionlake.blob.core.windows.net/mobilitytwin/stib_vehicle_trip/2026-11-16_00-00-00_to_2026-11-17_00-00-00.parquet
# The GTFS timetable that was valid on that day
curl -s -H "Authorization: Bearer $MOBILITYTWIN_TOKEN" -o gtfs.zip \
  "$API/stib/gtfs?timestamp=2026-11-16T12:00:00Z"
unzip -q gtfs.zip -d gtfs

The Parquet file has one row per vehicle and per poll. Its main columns are the following:

  • uuid identifies a vehicle for as long as it is tracked on one run.

  • lineId and routeId are the line number and its GTFS route.

  • tripId is the GTFS trip the vehicle is running. It is empty until the vehicle has called at its second stop, since which waiting vehicle makes the next departure cannot be known from the feed. It is inferred by the platform as the best match to the timetable.

  • delay is the delay in seconds at the last stop called at, negative when early.

  • status is STOPPED_AT or IN_TRANSIT_TO, and empty on the metro.

  • timestamp is the time of the poll in Unix seconds, and lon and lat the position in WGS84.

We convert the Parquet file into a CSV file with DuckDB. 

pip install duckdb
python3 -c "
import duckdb
duckdb.sql('''COPY (SELECT uuid, lineId, directionId, direction, pointId,
  distanceFromPoint, routeId, timestamp, tripId, startDate, startTime, delay,
  status, stopId, stopSequence, lon, lat
  FROM 'stib_2026-11-16.parquet') TO 'stib_positions.csv' (HEADER)''')"
