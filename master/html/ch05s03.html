Loading the Positions

We create a database stib with the extension, and set its time zone to the one of Brussels, in which all the times of this chapter are shown. 

CREATE EXTENSION mobilitydb CASCADE;
ALTER DATABASE stib SET TimeZone = 'Europe/Brussels';

We then connect again and load the CSV file, from the directory of the downloaded files. 

DROP TABLE IF EXISTS stib_input;
CREATE TABLE stib_input (
  uuid text,
  line_id text,
  direction_id text,
  direction integer,
  point_id text,
  distance_from_point float,
  route_id text,
  epoch double precision,
  trip_id text,
  start_date text,
  start_time text,
  delay integer,
  status text,
  stop_id text,
  stop_sequence integer,
  lon float,
  lat float
);
\copy stib_input FROM 'stib_positions.csv' WITH (FORMAT csv, HEADER true)

DROP TABLE IF EXISTS stib_positions;
CREATE TABLE stib_positions AS
SELECT uuid AS vehicle_id, line_id, route_id, direction, trip_id, delay, status,
  to_timestamp(epoch) AS t,
  ST_Transform(ST_Point(lon, lat, 4326), 31370) AS geom
FROM stib_input;
CREATE INDEX ON stib_positions (vehicle_id, t);

The table stib_positions keeps the columns we use, with the time as a timestamptz and the position in the Belgian Lambert 72 projection (EPSG:31370), so that distances are measured in metres. 

SELECT count(*) AS positions, count(DISTINCT vehicle_id) AS runs,
  min(t), max(t) FROM stib_positions;
--  positions | runs  |              min              |             max              
-- -----------+-------+-------------------------------+------------------------------
--    2256768 | 24711 | 2026-11-16 01:00:00.109004+01 | 2026-11-17 00:59:59.22366+01
-- (1 row)
