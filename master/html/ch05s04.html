Building the Trajectories

We build one row per vehicle run, with its trajectory and three temporal attributes. 

DROP TABLE IF EXISTS stib_vehicles;
CREATE TABLE stib_vehicles AS
SELECT vehicle_id, line_id, route_id,
  appendInstant(tgeompoint(geom, t), 'linear', 1000.0, interval '2 minutes'
    ORDER BY t) AS trip,
  appendInstant(ttext(trip_id, t), 'step', interval '2 minutes' ORDER BY t)
    FILTER (WHERE trip_id IS NOT NULL) AS trip_id,
  appendInstant(tint(delay, t), 'step', NULL, interval '2 minutes' ORDER BY t)
    FILTER (WHERE delay IS NOT NULL) AS delay,
  appendInstant(ttext(status, t), 'step', interval '2 minutes' ORDER BY t)
    FILTER (WHERE status IS NOT NULL) AS status
FROM stib_positions
GROUP BY vehicle_id, line_id, route_id;

DELETE FROM stib_vehicles WHERE numInstants(trip) = 1;
UPDATE stib_vehicles v
SET trip = (SELECT tgeompointSeqSet(array_agg(s ORDER BY startTimestamp(s)))
  FROM unnest(sequences(v.trip)) AS s WHERE numInstants(s) > 1)
WHERE numSequences(v.trip) > 1;
DELETE FROM stib_vehicles WHERE trip IS NULL;
CREATE INDEX ON stib_vehicles USING gist (trip);

The aggregate function appendInstant appends the positions of a run in time order. Its arguments give the interpolation, linear for the position and step for the attributes, and the gaps: a new sequence starts when two consecutive positions are more than 1,000 metres or 2 minutes apart, so that the trajectory does not invent a path across a missing stretch of data. A temporal text trip_id keeps the GTFS trip of the run over time, since a run can carry several trips and a trip can be carried by several runs when the platform loses a vehicle and finds it again. A temporal integer delay and a temporal text status keep the delay and the status at a stop. The trajectory keeps only the positions it needs: a position on the straight line between its neighbours at the matching time adds nothing. 

SELECT count(*) AS runs, sum(numInstants(trip)) AS instants,
  sum(numSequences(trip)) AS sequences,
  pg_size_pretty(pg_total_relation_size('stib_vehicles')) AS size
FROM stib_vehicles;
--  runs  | instants | sequences | size  
-- -------+----------+-----------+-------
--  23875 |  1513338 |     26844 | 79 MB
-- (1 row)

The day's 2,256,768 positions become 1,513,338 instants. A run made of a single position, and an isolated position between two gaps, describe no movement and are removed by the DELETE and UPDATE statements above.
