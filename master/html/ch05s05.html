Loading the Routes and Stops

From the GTFS timetable of the day we only need the routes, which give the mode of each line, and the stops. 

DROP TABLE IF EXISTS routes;
CREATE TABLE routes (
  route_id text PRIMARY KEY,
  agency_id text,
  route_short_name text,
  route_long_name text,
  route_desc text,
  route_type integer,
  route_url text,
  route_color text,
  route_text_color text
);
\copy routes FROM 'gtfs/routes.txt' WITH (FORMAT csv, HEADER true)

DROP TABLE IF EXISTS stops;
CREATE TABLE stops (
  stop_id text PRIMARY KEY,
  stop_code text,
  stop_name text,
  stop_desc text,
  stop_lat float,
  stop_lon float,
  zone_id text,
  stop_url text,
  location_type integer,
  parent_station text,
  wheelchair_boarding integer
);
\copy stops FROM 'gtfs/stops.txt' WITH (FORMAT csv, HEADER true)
ALTER TABLE stops ADD COLUMN stop_geom geometry(Point, 31370);
UPDATE stops SET stop_geom = ST_Transform(ST_Point(stop_lon, stop_lat, 4326), 31370);
CREATE INDEX ON stops USING gist (stop_geom);

The column route_type is 0 for the tram, 1 for the metro and 3 for the bus. The chapter on GTFS data shows how to build the planned trips from the rest of the timetable, to compare them with the trips that ran.
