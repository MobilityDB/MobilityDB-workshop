Detecting Incidents

A vehicle that stays still for several minutes away from any stop is a sign of an incident: a breakdown, an accident, or a blocked track. The function stops returns the parts of a trajectory during which the vehicle stayed within a given distance, here 20 metres, for at least a given duration, here 3 minutes. We ignore the metro, which is only observed at its stations, the stops at the start and at the end of a run, which are layovers at a terminus, and the stops within 50 metres of a stop of the network. The status of the feed cannot replace this last test: a vehicle waiting at a terminus can be reported IN_TRANSIT_TO its first stop. 

DROP TABLE IF EXISTS stopped;
CREATE TABLE stopped AS
SELECT v.vehicle_id, v.line_id, s.stop
FROM stib_vehicles v JOIN routes r USING (route_id),
  unnest(sequences(stops(v.trip, 20.0, interval '3 minutes'))) AS s(stop)
WHERE r.route_type <> 1
  AND startTimestamp(s.stop) > startTimestamp(v.trip)
  AND endTimestamp(s.stop) < endTimestamp(v.trip)
  AND NOT EXISTS (SELECT 1 FROM stops p
    WHERE ST_DWithin(p.stop_geom, startValue(s.stop), 50.0));
SELECT count(*) AS alarms, count(DISTINCT vehicle_id) AS vehicles FROM stopped;
SELECT line_id, startTimestamp(stop)::time(0) AS since,
  duration(stop)::interval(0) AS stopped_for, n.stop_name AS nearest_stop,
  round(ST_Distance(startValue(stop), n.stop_geom)) AS metres
FROM stopped, LATERAL (SELECT stop_name, stop_geom FROM stops
  ORDER BY stop_geom <-> startValue(stop) LIMIT 1) AS n
ORDER BY duration(stop) DESC LIMIT 5;

A vehicle crawling in traffic moves, but slowly. The function speed returns the speed of a trajectory in metres per second as a temporal float, the comparison #< returns a temporal Boolean that is true while the speed is below 5 km/h, and the function whenTrue returns the periods during which it is true. We keep the periods of at least 5 minutes during which the vehicle moved at least 50 metres, which leaves out the time spent at a stop. 

DROP TABLE IF EXISTS slowed;
CREATE TABLE slowed AS
SELECT v.vehicle_id, v.line_id, p AS period, length(atTime(v.trip, p)) AS metres
FROM stib_vehicles v JOIN routes r USING (route_id),
  unnest(spans(whenTrue(speed(v.trip) #< 5 / 3.6))) AS p
WHERE r.route_type <> 1 AND duration(p) >= interval '5 minutes'
  AND length(atTime(v.trip, p)) >= 50.0;
SELECT extract(hour FROM lower(period)) AS hour, count(*) AS alarms
FROM slowed GROUP BY 1 ORDER BY 1;
