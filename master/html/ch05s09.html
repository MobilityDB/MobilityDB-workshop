Serving Vector Tiles

A map shows the trajectories as Mapbox vector tiles. The following function returns the tile z/x/y of the trajectories during a period. The function asMVTGeom clips a trajectory to the tile and returns its geometry in tile coordinates together with the time of each of its points, which a client uses to animate the vehicles. 

CREATE OR REPLACE FUNCTION stib_tile(z integer, x integer, y integer,
  p_start timestamptz, p_end timestamptz)
RETURNS bytea AS $$
  WITH bounds AS (
    SELECT ST_TileEnvelope(z, x, y) AS geom ),
  vals AS (
    SELECT v.vehicle_id, v.line_id,
      asMVTGeom(transform(s, 3857), stbox(b.geom)) AS geom_times
    FROM stib_vehicles v, bounds b,
      unnest(sequences(atTime(v.trip, span(p_start, p_end)))) AS s
    WHERE v.trip && stbox(ST_Transform(b.geom, 31370), span(p_start, p_end)) ),
  mvtgeom AS (
    SELECT (geom_times).geom, (geom_times).times, vehicle_id, line_id
    FROM vals
    WHERE GeometryType((geom_times).geom) <> 'GEOMETRYCOLLECTION' )
  SELECT ST_AsMVT(mvtgeom) FROM mvtgeom;
$$ LANGUAGE sql STABLE PARALLEL SAFE;

Each sequence of a trajectory is a feature of its own. When the part of a sequence inside the tile is made of lines and of an isolated position, asMVTGeom returns a collection of lines and a point, which a vector tile cannot encode; the function leaves these rare pieces out. 

SELECT length(stib_tile(13, 4195, 2748, '2026-11-16 08:00', '2026-11-16 08:15'))
  AS bytes;
--  bytes 
-- -------
--  61423
-- (1 row)

A tile server that publishes PostgreSQL functions, such as pg_tileserv or Martin, serves this function to a web map.
